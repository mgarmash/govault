# Translating GoVault

GoVault shows its text through NSGo's message catalogs. This guide covers how the catalogs work, how to write a translation, and the words GoVault uses for its key terms.

## Languages

GoVault ships in English, the source language. These translations are planned:

| File | Language | Name in the language setting |
|---|---|---|
| `zh-Hans.yaml` | Chinese (Simplified) | 简体中文 |
| `zh-Hant.yaml` | Chinese (Traditional), Taiwan usage | 繁體中文 |
| `ja.yaml` | Japanese | 日本語 |
| `ko.yaml` | Korean | 한국어 |
| `de.yaml` | German | Deutsch |
| `fr.yaml` | French | Français |
| `es.yaml` | Spanish | Español |
| `pt-BR.yaml` | Portuguese (Brazil) | Português (Brasil) |
| `ru.yaml` | Russian | Русский |

Right-to-left languages are not supported yet.

## How the catalogs work

The catalogs live in `cmd/govault/locales/`, beside `cmd/govault/nsgo.yaml`:

- `en.yaml` holds every message in English. Each message has a key and its text in [ICU MessageFormat](https://unicode-org.github.io/icu/userguide/format_parse/messages/). Where a message could be read more than one way, a `description` says where it shows and what it means.
- A translation is one file per language, named by its BCP 47 tag, such as `de.yaml`. It uses the same keys, each with a plain translated string. Do not copy the descriptions.
- `catalog_gen.go` is generated. `go tool nsgo i18n ./cmd/govault` checks the catalogs and rewrites it; `dev`, `build` and `test` do the same. Never edit it by hand.

A translation file looks like this:

```yaml
cancel: Abbrechen
itemCount: "{count, plural, one {# Eintrag} other {# Einträge}}"
deleteFolderMessage: "Einträge in „{name}“ werden nach „Kein Ordner“ verschoben."
```

A key missing from a translation shows in English, so a partial translation works, and the check names what is missing. A key in a translation that is not in `en.yaml` is an error.

The language GoVault shows follows the system, unless the user picks one in **Settings → General → Language**. A system language GoVault has no catalog for shows English.

## Writing messages

### Placeholders

Text in braces is filled in when the message shows. Keep the placeholder name exactly as it is, and move it to wherever your language puts it:

```yaml
# en.yaml
unlockWith: "Unlock with {method}"
# ja.yaml
unlockWith: "{method}でロック解除"
```

Never translate a placeholder's name. Placeholders that hold user data, such as `{name}`, `{file}` or `{query}`, show that data as it is.

### Plurals

Counts use `plural`, with one case per CLDR plural category of your language. `#` is the number, written as your language writes numbers.

```yaml
# en.yaml: one, other
itemCount: "{count, plural, one {# item} other {# items}}"
# ru.yaml: one, few, many, other
itemCount: "{count, plural, one {# запись} few {# записи} many {# записей} other {# записи}}"
# ja.yaml: other only
itemCount: "{count, plural, other {# 件}}"
```

The categories are: Chinese, Japanese and Korean `other`; German and Spanish `one`, `other` (Spanish also takes `many`); French and Brazilian Portuguese `one`, `many`, `other`; Russian `one`, `few`, `many`, `other`. `go tool nsgo i18n` warns of a missing or unknown category.

### Choices (select)

A `select` picks a sentence by a word GoVault passes. Translate each sentence, but keep the words before the braces, such as `copyPassword`, `login` or `other`, exactly as they are:

```yaml
repromptPrompt: "{action, select, copyPassword {Geben Sie Ihr Master-Passwort ein, um das Passwort zu kopieren.} … other {Geben Sie Ihr Master-Passwort ein, um fortzufahren.}}"
```

Each case is a whole sentence, so you can phrase every one as your language needs.

### Dates and numbers

`{date, date, medium}`, `{date, time, short}` and `{date, date, ::MMMd}` format a date as your language does; `{count, number, integer}` and `{size, number, ::.0}` format a number. Keep these as they are and move them where they belong; do not write a date or number format yourself.

### Punctuation

- An ASCII apostrophe `'` starts a quoted part in ICU. Write `’` (U+2019), or your language's own apostrophe, instead.
- Use your language's quotation marks, such as „…“ in German, « … » in French and Russian, and 「…」 in Japanese and Chinese.
- Keep the ellipsis `…` on menu items and buttons that open a dialog, such as `Export…`.
- Messages described as in capitals, such as `cardPictureCardholder`, show on the picture of a card; write them in capitals where your language has them.

### Length

Translations are often longer than English. Prefer the short form your language uses in apps. Run the pseudo locale to see how longer text fits:

```sh
go tool nsgo dev -lang en-XA ./cmd/govault
```

It shows every message accented, bracketed and a third longer, so text that is cut or not in the catalog stands out. `go test ./cmd/govault/preview -run Pseudo` walks the screens in it and fails on any text outside the catalog.

### What not to translate

- The product name **GoVault**.
- Brand and product names: **Bitwarden**, **Vaultwarden**, **Touch ID**, **Face ID**, **Windows Hello**, **YubiKey**, **Duo**, **macOS**, **Dock**.
- Technical names: Argon2id, PBKDF2-SHA256, SSH, Ed25519, `SSH_AUTH_SOCK`, TOTP, `otpauth://`, HTTP, HTTPS, JSON, MiB.

## Glossary

GoVault is a Bitwarden client, so its users know Bitwarden's words. Use the same translation Bitwarden's desktop app uses for each term: look it up in [`bitwarden/clients`](https://github.com/bitwarden/clients), `apps/desktop/src/locales/<lang>/messages.json` (for example `de/messages.json`, `zh_CN`, `zh_TW`, `pt_BR`), by searching the English text. Where Bitwarden has no translation, choose the word a password manager in your language would use, and use it everywhere.

| Term | Meaning in GoVault |
|---|---|
| Vault | The user's encrypted collection of items. |
| Item | One entry in the vault: a login, card, identity, secure note or SSH key. |
| Login | An item with a username, password, websites and verification code. |
| Card | A payment card item. |
| Identity | An item with a person's name, address and documents. |
| Secure Note | An item that holds only text. |
| SSH Key | An item with an SSH private and public key. |
| Folder | A personal grouping of items. |
| Collection | A shared grouping of an organization's items. |
| Organization | A group, such as a company or family, that shares items. |
| Favorite | An item marked to show under Favorites. |
| Trash | Where deleted items wait until they are restored or deleted permanently. |
| Archive | As a noun, where archived items are kept; as a verb, moving an item there. The descriptions say which. |
| Passkey | A FIDO2 credential stored in a login item. |
| Master password | The password that unlocks the vault. |
| Two-step login | Bitwarden's name for two-factor authentication. |
| Sync | Fetching the vault from the server. |
| Lock / Unlock | Closing the vault on this device, and opening it again. |
| Reprompt | Asking for the master password again before an item's secrets show. |
| Attachment | A file stored with an item. |
| Generator | The password and passphrase generator. |
| Passphrase | A generated password made of words. |
| Vault Health | GoVault's report of reused, weak and insecure passwords, expiring cards and duplicate logins (Bitwarden's reports). |

## NSGo's own words

GoVault's windows also show words from NSGo, the framework it is built with: the menu bar's standard items, the update alerts, and what screen readers say of controls. NSGo ships English and Simplified Chinese. For any other language, add NSGo's messages to the same translation file, under a key that names the NSGo package:

```yaml
# cmd/govault/locales/de.yaml
cancel: Abbrechen

github.com/nsgo-dev/nsgo/updater/locales:
  updateAvailable: "Eine neue Version von {app} ist verfügbar"
  update: Aktualisieren
  later: Später

github.com/nsgo-dev/nsgo/desktop/locales:
  …

github.com/nsgo-dev/nsgo/base/locales:
  …
```

The keys and English texts are in NSGo's own catalogs, `base/locales/en.yaml`, `desktop/locales/en.yaml` and `updater/locales/en.yaml`, in the NSGo module (`go list -m -f "{{.Dir}}" github.com/nsgo-dev/nsgo`). Their `zh-Hans.yaml` files show a finished translation. The same ICU rules apply. For Simplified Chinese these sections are optional; they replace NSGo's own translation.

`go tool nsgo i18n ./cmd/govault` warns of each NSGo package with no translation for a language GoVault ships, and checks every supplied key and placeholder against NSGo's catalogs.

## Checking a translation

```sh
go tool nsgo i18n ./cmd/govault        # check the catalogs and regenerate catalog_gen.go
go tool nsgo check ./cmd/govault       # the same check, failing if catalog_gen.go is stale
go test ./cmd/govault/...              # includes the catalog and pseudo-locale tests
go tool nsgo dev -lang de ./cmd/govault  # run the app in a language
```

A built GoVault also starts in a language with `--nsgo-lang=de`; `-demo` opens a sample vault without a server.
